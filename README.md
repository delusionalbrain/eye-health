# EyeEase

A minimal desktop app that reminds you to take eye breaks every 20 minutes — built with Electron.

---

## The 20-20-20 Rule

Every **20 minutes**, look at something **20 feet away** for **20 seconds**.  
That's it. EyeEase just makes sure you don't forget.

---

## Features

- Desktop notification every 20 minutes
- Runs quietly in the background
- Fixed window size — no clutter
- Minimal UI with a cyberpunk-inspired design

---

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/)
- npm

### Installation

```bash
git clone https://github.com/your-username/eyeease.git
cd eyeease
npm install
```

### Run

```bash
npm start
```
